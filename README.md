# 🤟 SignLink

SignLink is an AI-powered sign language recognition system that bridges the communication gap between sign language users and non-sign language users. By leveraging computer vision and machine learning, SignLink detects hand gestures in real time and translates them into meaningful text.

---

## 📌 Overview

Communication barriers can make daily interactions challenging for individuals who rely on sign language. SignLink aims to provide an accessible and intelligent solution by recognizing sign language gestures through a webcam and converting them into readable text.

## 🚀 How It Works

1. User performs a sign language gesture in front of the webcam.
2. OpenCV captures and processes the image.
3. The trained machine learning model analyzes the gesture.
4. The predicted sign is converted into readable text.
5. The output is displayed to the user in real time.
